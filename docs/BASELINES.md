# Evaluation baselines

Raw measurements per provider/model for the stable benchmark tasks in `src/eval/tasks.js` (and the repository-scale dogfood task in
`src/eval/dogfood.js`). There is **no composite score and no ranking**: each row is one run, and rows are only comparable for the same task.
Success is an objective check on the resulting repository (for example "the test suite passes"), never the model's own claim.

Columns: `validation` — BLUSWAN's own validation status after the run; `turns` / `tools` — model turns and tool calls; `dup` — identical repeated tool
calls; `files` / `extra` — files changed / files changed beyond those the task needed; `tokens`; `time`.
