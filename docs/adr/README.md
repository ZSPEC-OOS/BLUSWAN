# Architecture decision records (historical)

ADRs 001–005 record decisions of the former V1/V2 execution architecture (task state machine, bounded remediation,
context budget enforcement, quality signals). That code has been removed. They are kept as history and are **not** a
description of the current system — see [`../ARCHITECTURE.md`](../ARCHITECTURE.md).

Several of their ideas survive in the current design in a different form: hard resource limits, deterministic context
budgeting, and validation as infrastructure rather than model judgement.
